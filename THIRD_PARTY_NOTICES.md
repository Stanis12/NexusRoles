# Third-party notices and credits

This file records upstream authorship, asset provenance, and third-party
licenses known for NexusRoles. Credits do not transfer ownership or grant
permissions beyond the applicable license.

## Upstream projects

- **KingRobin72 / BobisMods** — creator of the original REPORoles mod and its
  core role design. [Thunderstore page](https://thunderstore.io/c/repo/p/BobisMods/REPORoles/)
- **R3Labs** — maintainer of REPORoles Classic and its source lineage.
  [Thunderstore page and upstream asset statement](https://thunderstore.io/c/repo/p/R3Labs/REPORoles_Classic/)
- **Jettcodey** — REPO-Roles-CE source repository used in this project's
  lineage. [GitHub repository](https://github.com/Jettcodey/REPO-Roles-CE)
- **Pxntxrez** — Player Upgrade/StatsManager and REPOConomyPlus compatibility
  work, credited by the REPORoles Classic maintainers.
- **Grimgar** — original icon and in-game mod art, credited by the REPORoles
  Classic maintainers. Those original assets are not intended to be included
  in the recreated bundle.
- **surf** — earlier mana UI design contribution, credited by the REPORoles
  Classic maintainers.
- **101m_m** — original Mods Shop upgrade designs, credited by the REPORoles
  Classic maintainers. NexusRoles uses recreated replacement assets.
- **Théo Hay** — NexusRoles maintenance, fixes, language support, and new
  contributions. Original contributions are covered by `LICENSE-MIT.txt`.

The REPORoles Classic Thunderstore page says its code license applies to code
and that its original author did not publicly release the original assets. It
also says the Classic maintainers had permission to distribute those assets
only as AssetBundles with their mod, not as public reusable assets. NexusRoles
therefore uses a recreated bundle. The current upstream code license text and
any permission covering this fork have not been independently confirmed;
consult the upstream owners before redistribution if the terms are unclear.

## NexusRoles package icon

The current `assets/icon.png` is a custom geometric design generated by the
included `tools/create_icon.py` script. It uses no third-party image or font.
The project maintainer offers the icon under CC BY 4.0, attributed to
NexusRoles / Théo Hay; see `LICENSE` and the linked license above.
The earlier Tumblr-supplied image is preserved only in the ignored `local-only/`
folder and is excluded from Git and release archives.

## Font

The asset project contains `font.ttf` and the Noto Sans SIL Open Font License
1.1 notice at
`assets/unity/NuageRolesAssetBundle/Assets/NuageRoles/SourceArt/Gui/NotoSans-OFL.txt`.
The matching notice is copied to the root of the Thunderstore archive. Preserve
it when distributing the font or bundle that contains it.

These are separate projects declared in `manifest.json`; they are not included
or relicensed by NexusRoles:

- [BepInEx](https://github.com/BepInEx/BepInEx)
- [REPOLib by Zehs](https://thunderstore.io/c/repo/p/Zehs/REPOLib/)
