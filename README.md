# NexusRoles

NexusRoles is a maintained fork of [REPO Roles Classic](https://thunderstore.io/c/repo/p/R3Labs/REPORoles_Classic/) ([source repository: Jettcodey/REPO-Roles-CE](https://github.com/Jettcodey/REPO-Roles-CE)), which is itself based on [REPO Roles](https://thunderstore.io/c/repo/p/BobisMods/REPORoles/) by KingRobin72 / BobisMods.

Source repository: [Stanis12/NexusRoles](https://github.com/Stanis12/NexusRoles).

NexusRoles keeps that role-based gameplay foundation, updates the mod for the current R.E.P.O. modding stack, expands configuration, includes an Engineer network-ownership/charge verification change, and ships a recreated `NexusRoles_assets` bundle. In-game role text supports English, Russian, and Ukrainian, selected from the system language. Engineer charging still needs confirmation in a multiplayer game.

## Quick Info

- Select your role in **Mods > NexusRoles**, or leave it on Random.
- When a game begins, each player receives a role automatically.
- Press **R** by default to show or hide your current role info.
- NexusRoles keybinds and important role settings are configurable in-game.
- Advanced role balance values are available in the config file.

## Available Roles

- **Runner** - Moves faster and has more stamina.
- **Tank** - Has more health and passive regeneration, but reduced speed.
- **Gambler** - Receives one random buff and one random debuff each game.
- **Strongman** - Has much stronger grab/melee strength.
- **Ranged Looter** - Has increased grab range and slightly more strength.
- **Athletic** - Gains more stamina, strength, and jump force.
- **Mage** - Uses mana to cast healing, stamina, speed, jump, and overcharge spells.
- **Reaper** - Grows stronger when enemies are defeated.
- **Scout** - Uses less stamina and can temporarily see enemies through walls.
- **Regular** - Just a regular Semibot.
- **Engineer** - Uses stamina to recharge held items.
- **Acrobat** - Moves faster and jumps higher, but has less health and grab strength.
- **Savior** - Sacrifices part or all of their health to revive a nearby ally. Ability cooldown: 120 seconds.

## Upgrades

- **Mana Regeneration** - Reduces Mage mana regeneration time. Max level: 5.
- **Scout Cooldown** - Reduces Scout ability cooldown time. Max level: 5.

Role upgrades are registered through REPOLib and can be disabled separately from role selection.

## Assets

The included `NexusRoles_assets` bundle was recreated for NexusRoles with a Unity source project in this repository. The old closed asset bundle from the upstream forks is not used.

The Unity asset rebuild project lives under:

```text
assets/unity/NexusRolesAssetBundle
```

## Development

Use .NET SDK 9.0.100 or a compatible .NET 9 SDK. From this repository root:

```powershell
dotnet restore src/NexusRoles.Plugin/NexusRoles.Plugin.csproj --locked-mode
dotnet build src/NexusRoles.Plugin/NexusRoles.Plugin.csproj -c Release --no-restore -p:CopyFilesToPluginOutputDirectoryOnBuild=false
./tools/package.ps1
```

The packaged zip is written to:

```text
release/NexusRoles-<version>.zip
```

See [`docs/RELEASING.md`](docs/RELEASING.md) for GitHub and Thunderstore publishing.
